## 为什么归档而非删除

- 这些文档含当时的证据、验收记录与决策理由，删除会丢失可追溯性；
- 但其中的版本号、Provider 数量、IPC 数字等**会随代码演进失真**，留在根目录易被误读为现行规范；
- 统一迁入本目录并在 `kone-PRD.md §0.2` 登记为「非活规范」，既保留证据又消除歧义。

## 引用规则

- 历史文档（如 `CHANGELOG.md`）仍以旧根路径引用时，`scripts/verify-doc-consistency.cjs`
  通过 `resolveMovedDoc()` 将其解析到本目录，**不要求改写历史条目**；
- 新增文档请勿再放入本目录；本目录只接收「时点快照」。
