# Kone 智能获客（V1.2）用户快速上手手册

Kone 是一款面向外贸 B2B 场景的本地智能获客工作台：搜索、ICP 评分、深度分析均在您自己的电脑上完成，数据默认不出本机；只有您主动推送时，精选线索才会交接给云端自动化流程。

---

## 一、安装与激活

1. 运行安装包 `Kone-Intellect-Setup-1.2.0.exe`，按向导完成安装（可自定义安装目录）。
2. 首次启动进入激活页：
   - 复制页面上的「设备识别码」发给您的顾问，换取激活码后粘贴激活；
   - 或点击「开启 7 天免费试用」先体验（试用版每次搜索结果上限 10 条、搜索间隔 15 秒）。
3. 授权与设备绑定，请勿手动修改系统时间，时间异常会触发保护性锁定。

## 二、五步开始获客

| 步骤 | 位置 | 操作 |
|---|---|---|
| 1. 配置 AI 密钥 | 系统设置 → 基础配置 | 填写 LLM 与搜索提供商密钥，点击「测试连接」验证 |
| 2. 描绘 ICP 画像 | 系统设置 → ICP 画像 | 填写目标产品、买家角色、核心优势、负向 ICP |
| 3. 发起智能搜索 | 智能获客 | 输入关键词 + 国家 + 城市，按需勾选高级质量控制 |
| 4. 保存与跟进 | 线索管理 | 一键保存高分线索，发起 AI 深度分析、生成开发信 |
| 5. 导出与云端 | 线索管理 / 自动化序列 | 导出 CSV；高级版可清洗邮箱并推送云端发送队列 |

> 应用内任何页面均可点击左下角「使用指南」查看同样内容的操作说明。

## 三、搜索结果怎么看

- **待评估 / 百分比**：列表先展示基础线索，AI 评分会逐条流式补全；「待评估」表示评分尚未完成，不代表低分。
- **推断角色 / 跟进建议 / 风险提示**：由 AI 依据官网与公开商业信号生成，建议结合人工判断使用。
- **降级提示不是故障**：看到「地图定位受限，正在尝试扩大识别范围...」或「未发现地图商户，已自动为您补位全局网页线索...」时，系统正在自动切换搜索策略，无需手动重试。
- **盲评标注**：「基于简介轻量评估（官网无法访问）」表示该条评分基于公开简介完成，建议人工复核。

## 四、伴随式后台巡航（Autopilot）

巡航可在后台批量执行「国家 + 关键词 + 目标数量」任务，自动过滤低分线索后写入线索库。它是**本地后台功能**，运行边界如下：

- 电脑保持开机、应用保持运行；
- 系统不休眠、网络在线；
- 关机或断网后巡航自动暂停，恢复后可继续。

这与高级版的云端自动化不同：线索交接给 N8N 后，即使本机关机，云端流程仍会继续执行。

## 六、常见问题

**Q：删除了配置文件，试用会重置吗？**
不会。系统采用双锚点机制，重装或删除配置不会重置试用记录。

**Q：提示「系统环境异常，请恢复标准北京时间」？**
软件检测到系统时间被回拨。请恢复正确的系统时间并开启网络时间同步，再重新打开应用。

**Q：断网后还能用吗？**
本地功能（线索查看、编辑、导出）可正常使用；搜索与 AI 评分需要网络。授权校验在离线时使用最近一次可信时间锚点，不会因断网锁定。

**Q：线索数据会被上传吗？**
不会自动上传。只有点击「发送至云端」时，才会推送您选中的、经过裁剪的精选线索。
