## ❓ 第八部分：客户关心问题汇总 (FAQ)

**Q1：我的数据安全吗？你们会偷看我的客户资料吗？**  
答：绝不会。Kone 采用本地部署架构，您的客户名单存储在您自己的电脑上。只有在您主动触发云端任务时，系统才会加密传输必要信息。我们无法，也无权访问您的私有数据库。

**Q2：我买了一个码，可以在家里和公司的两台电脑同时用吗？**  
答：不可以。Kone 的激活码采用“硬件绑定（Machine ID）”机制，严格一机一码。如需在多台设备使用，请购买增量授权或选择企业版套餐。

**Q3：为什么我必须自己去买 API 密钥？不能内置好直接用吗？**  
答：为了确保您的业务隐私和搜索独立性。自带密钥可以确保您的搜索行为不被平台监控，同时也能让您根据业务量灵活控制成本，无需向我们支付高额的数据溢价差价。

**Q4：试用期到了，我搜集的数据会丢失吗？**  
答：不会。试用期结束后，软件的高级功能（如搜索、AI 分析）会锁定，但您之前搜集并保存的线索依然完好地保留在本地数据库中，您随时可以浏览或导出。
